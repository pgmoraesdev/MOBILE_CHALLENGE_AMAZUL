## Sobre a solução

A tecnologia nuclear está presente na saúde, agricultura, indústria, geração de energia e pesquisa científica, mas suas aplicações ainda são pouco conhecidas por parte da população.

O Damy propõe ensinar esse conteúdo por meio de quizzes, jogos da memória e quebra-cabeças. O objetivo é estimular a curiosidade, apresentar aplicações do cotidiano e incentivar a aprendizagem de forma interativa. Nas atividades competitivas, a proposta é permitir a comparação de desempenho pelas pontuações.

Nesta Sprint, o protótipo conta com um quiz funcional, seleção de atividades do cotidiano, cadastro e edição de temas e criação de sessões com código de sala. Os demais jogos e a participação em salas estão previstos para etapas futuras. Os dados ficam em memória durante a execução do aplicativo.

## Empresa relacionada

A **AMAZUL (Amazônia Azul Tecnologias de Defesa S.A.)** é uma empresa pública brasileira vinculada ao Ministério da Defesa por meio da Marinha do Brasil, com atuação em tecnologia nuclear, defesa e soberania nacional.

Entre suas frentes de atuação estão o Programa Nuclear da Marinha, o Programa de Desenvolvimento de Submarinos (PROSUB) e o Programa Nuclear Brasileiro, incluindo projetos como o Reator Multipropósito Brasileiro (RMB).

## Como executar

É necessário ter o Flutter instalado, com Dart compatível com a versão `^3.13.5` definida no projeto, e um emulador, dispositivo conectado ou navegador Chrome disponível.

Na pasta do projeto, instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo e selecione o dispositivo:

```bash
flutter run
```

Para executar diretamente no Chrome:

```bash
flutter run -d chrome
```

## Tecnologias utilizadas

- Flutter e Dart.
- Material Design 3 para os componentes e o tema visual.
- Lucide Flutter para os ícones.
- Navigator para a navegação entre telas.
- StatefulWidget e setState para o gerenciamento de estado.
- Flutter Test e Flutter Lints para testes e análise de código.
